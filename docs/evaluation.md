## 真实简历评测

真实模型评测使用固定的四份简历：中文 AI、中文 Data Science、英文 AI、英文 Data Science。每份简历至少记录以下字段：

- 姓名、邮箱、电话、所在地；
- 教育经历数量、学校、专业/学位、时间；
- 工作经历数量、公司、职位、时间；
- 项目经历数量、项目名称、时间、角色和描述；
- 技能数量和来源证据。

字段级准确率按下面的方式计算：

```text
字段准确率 = 正确字段数 / 参与评测的非空标准字段数
条目数量准确率 = 数量正确的简历数 / 简历总数
表单回填成功率 = 正确完成映射的简历数 / 简历总数
```

评测时必须把 `Resume Extractor` 和 `Resume Form Filler` 的结果分开记录，不能只看最终页面是否有内容：

1. Extractor 输出 `ResumeProfile`；
2. Form Filler 输出 `form_mapping`；
3. 将两者分别与人工校验的 gold JSON 比较；
4. 记录模型调用次数、输入/输出 Token、耗时和失败原因。

## 注意事项

离线 100% 只代表安全策略、数据边界和固定工作流探针通过，不代表模型对任意简历都有 100% 的字段准确率。对外展示时应同时报告真实简历的字段级准确率和失败案例。
