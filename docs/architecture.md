# MacPilot 架构说明

```text
┌────────────────────────────────────────────────────┐
│ Tauri/React Desktop                                │
│ 任务输入 · 时间线 · 审批 · 结果预览                 │
└───────────────────────┬────────────────────────────┘
                        │ HTTP
┌───────────────────────▼────────────────────────────┐
│ FastAPI API                                         │
│ tasks · messages · approvals · events               │
└───────────────────────┬────────────────────────────┘
                        │
┌───────────────────────▼────────────────────────────┐
│ LangGraph workflow                                  │
│ Planner → Researcher → Critic → Approval → Finalizer│
│ checkpoint · retry · context budget · response cache │
└───────────────┬──────────────────────┬──────────────┘
                │                      │
      ┌─────────▼─────────┐  ┌─────────▼─────────┐
      │ Policy tools       │  │ Local persistence │
      │ files · documents  │  │ SQLite tasks     │
      │ browser allowlist  │  │ steps · events   │
      └────────────────────┘  │ approvals · cache│
                              └─────────┬─────────┘
                                        │
                              ┌─────────▼─────────┐
                              │ Phase 5 evaluator │
                              │ 50 regression     │
                              │ tasks + metrics   │
                              └───────────────────┘
```

模型负责计划、解释和审查；工具负责执行；策略层在工具入口处拒绝越权路径、未授权域名、
只读模式下的写入和网页中的指令注入。所有工具调用、模型用量、审批和异常进入事件表，
因此桌面时间线和 Phase 5 报告使用同一份事实来源。

缓存只缓存带版本号的模型文本响应。缓存命中不会跳过工具、审批或策略判断；过期响应会
被删除。上下文裁剪保留系统消息和最新对话，优先丢弃较旧的中间消息。
