# MacPilot 3 分钟 Demo 讲稿

1. **输入目标（20 秒）**：输入“读取项目资料，整理定位和当前能力，并标注来源”。展示
   桌面端创建任务。
2. **计划与执行（45 秒）**：展示 Planner、Researcher、Critic、Finalizer 时间线，
   打开事件记录，说明文件和网页工具都经过白名单。
3. **失败恢复（35 秒）**：让 Critic 返回缺少来源，展示 Researcher 自动重试一次，
   并指出 checkpoint 让任务状态可恢复。
4. **安全拦截（40 秒）**：输入包含提交动作的目标，展示 `waiting_approval`、风险说明
   和预览；拒绝后展示未执行危险动作。
5. **评测证据（30 秒）**：运行 `macpilot-evals`，打开 JSON/Markdown 报告，展示 50 个
   回归任务、成功率、恢复率、未授权操作和 Prompt Injection 检测结果。
6. **收尾（10 秒）**：强调 LLM 负责决策，工具层负责执行，策略层负责权限，事件流负责
   调试和评测。
